# E-Commerce Logistics Data Analysis

## Project Overview
This project analyzes e-commerce logistics data to evaluate delivery performance, shipping costs, order status, and regional trends.

## Objectives
- Measure on-time delivery performance.
- Identify late deliveries and missing delivery dates.
- Analyze average shipping costs by carrier.
- Compare delivery performance across warehouses.
- Track monthly orders and delivery trends.
- Identify data-quality issues.

## Tools Used
- Microsoft Excel
- Python (Pandas, NumPy, Matplotlib)
- Power BI
- DAX

## Key Performance Indicators (KPIs)
- Total Orders
- On-Time Delivery Rate
- Average Shipping Cost
- Missing Delivery Dates

## Project Files
- `logistics_dataset.xlsx` — Source dataset
- `logistics_analysis.ipynb` — Python analysis
